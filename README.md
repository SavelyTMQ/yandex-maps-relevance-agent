# Оценка релевантности организаций для Яндекс.Карт

LLM-агент, оценивающий соответствие организации рубричному поисковому запросу
пользователя (например, «ресторан с верандой в Ижевске»).

## Задача

Пользователь ищет **тип места**, а не конкретную организацию. Нужно классифицировать
пару (запрос, организация) на 3 класса:

- **RELEVANT** — тип совпадает + все атрибуты подтверждены
- **PARTIAL** — смежный тип или атрибут не подтверждён (и не опровергнут)
- **IRRELEVANT** — тип не совпадает / атрибут опровергнут / другой город

## Результаты

| Модель | Accuracy (3-cls) | Macro F1 | Binary Accuracy |
|--------|:----------------:|:--------:|:---------------:|
| Baseline (Qwen2.5-3B, zero-shot) | 0.400 | 0.307 | 0.489 |
| **Агент v1** (LangGraph + GigaChat + tools) | **0.596** | **0.494** | **0.698** |
| Агент v2 (улучшенный промпт) | 0.602 | 0.482 | 0.696 |

**Ключевой инсайт:** агентный подход даёт **+20 п.п. accuracy** над baseline,
потому что для рубричных запросов данных карточки часто недостаточно —
нужна возможность самостоятельно дособирать информацию.

## Архитектура агента

Агент использует **LangGraph** с циклом «LLM → tool → LLM».


### Инструменты
1. **web_search** — поиск в интернете (DuckDuckGo) для проверки атрибутов
2. **fetch_website** — парсинг сайта организации (requests + BeautifulSoup)
3. **find_similar_examples** — RAG-поиск похожих примеров из train
   (эмбеддинги multilingual-e5-large, kNN по cosine similarity)

### LLM
GigaChat-2 (Сбер) — бесплатный LLM с поддержкой function calling из РФ.

## Анализ ошибок

Систематические паттерны ошибок (по анализу трейсов):

1. Мягкие атрибуты — агент занижал RELEVANT→PARTIAL из-за неподтверждённых субъективных признаков («недорого», «панорамный вид»)
2. Жёсткие атрибуты — завышал IRRELEVANT→RELEVANT, игнорируя определяющие слова («выездная», «категория Д», конкретный бренд)
3. Смежные типы — путал PARTIAL с IRRELEVANT для похожих сфер
4. Английская раскладка — не понимал запросы типа «,fyz» = «баня»
5. География — сверял только город, игнорируя улицы/метро

Все паттерны учтены в промпте v2 (см. agent/prompts.py).
